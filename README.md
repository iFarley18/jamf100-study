# Quiz Brian: Jamf 100

A free, no-login study site for the Jamf Certified Associate (Jamf 100) exam.

Open it here: https://ifarley18.github.io/jamf100-study/

- **Lookup / search:** press `/` or use the search box to instantly find official Jamf Pro facts (where settings live, enrollment, policies, groups, and more) and your study notes from the practice questions. Every official fact links to its source on [Jamf Pro documentation](https://learn.jamf.com/r/en-US/jamf-pro-documentation-current/Jamf_Pro_Documentation). After the first visit on https, the page is cached so search still works offline.
- **Quiz partner:** someone can read a question aloud, offer a hint if you are stuck, reveal the answer, and mark Got it, Close, or Missed. Progress is saved in the browser.
- **Practice exams A–D:** four original 50-question tests, with an optional 60-minute timer, scored against the real exam’s 40-out-of-50 (80%) pass mark.

These are original practice questions written from the public Jamf 100 course outline and Jamf Pro documentation. They are not questions from the real exam.

The site is a single `index.html` file (plus a small `sw.js` service worker for offline use on the website). You can also open `index.html` directly in a browser.

The GitHub Pages site updates from the `main` branch after a pull request is merged.
